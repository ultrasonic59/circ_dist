🎯 Circle Distance Finder
Qt 5.15 + OpenCV + VS 2019
Программа для поиска и сравнения окружностей на изображении, вычисления расстояния между похожими окружностями.
📸 Скриншот (пример)

│  📂 Открыть  │  🔍 Найти окружности  │  📏 Расстояние │
├─────────────────────────────────────────────────┤
│                                                 │
│            ●───────────●                        │
│          /             \                        │
│         │   d = 245px  │                        │
│          \             /                        │
│            ●───────────●                        │
│                                                 │
├─────────────────────────────────────────────────┤
│ ✅ Похожи: [0] ↔ [1]  расстояние = 245.32 px   │
└─────────────────────────────────────────────────┘
📋 Возможности
🔍 Автоматическое обнаружение окружностей (HoughCircles)
📏 Сравнение окружностей по радиусу и форме (циркулярность)
📐 Вычисление расстояния между центрами похожих окружностей
🖼️ Визуализация — зелёные контуры, синие линии между похожими
📝 Подробный лог — координаты, радиусы, циркулярность

🎮 Как пользоваться
📂 Открыть — выберите изображение (PNG, JPG, BMP, TIFF)
🔍 Найти окружности — программа обнаружит все окружности
📏 Похожие → расстояние — сравнит окружности попарно, покажет расстояние между похожими
Результат:
Зелёные контуры — все найденные окружности
Синяя линия — соединяет похожие окружности
Лог — координаты, радиусы, циркулярность, расстояние

🐛 Возможные проблемы
Проблема	Решение
LNK1104: cannot open file 'opencv_world455.lib'	Проверьте версию OpenCV в .pro и пути к библиотекам
opencv_world455.dll not found при запуске	Добавьте C:\opencv\build\x64\vc15\bin в PATH
Не найдены окружности	Уменьшите param2 (например, 30 → 20)
Слишком много ложных окружностей	Увеличьте param2 и minRadius
Не компилируется с C++17	Убедитесь, что в kit выбран MSVC 2019
